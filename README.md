# ToxicsAC — Official Downloads

ToxicsAC is a crossplay-aware Minecraft anti-cheat designed for Paper and Purpur servers.

## Download ToxicsAC

ToxicsAC provides separate JAR files for each supported Minecraft version.

| Minecraft Version | Server Software |
|---|---|
| 26.2 | Paper / Purpur |
| 26.3 | Paper / Purpur |

**[Download the latest ToxicsAC release](https://github.com/lexxi99/ToxicsAC-Releases/releases/latest)**

Please select the JAR matching your server's Minecraft version.

## Requirements

- Paper or Purpur
- PacketEvents installed on your server
- Compatible Java runtime
